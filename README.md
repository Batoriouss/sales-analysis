# Sales Analysis Project

## Описание
Анализ данных о продажах компании за 2024-2025 годы.

## Стек
- **Python** (Pandas, Matplotlib, Seaborn) — очистка данных и EDA
- **SQL** — бизнес-запросы
- **Power BI** — интерактивный дашборд

## Данные
- 7 479 транзакций продаж
- 500 клиентов, 120 продуктов, 8 менеджеров

## Ключевые находки
- Общая выручка: $10.16M, маржа: 27.7%
- Лидер по категориям: Accessories ($3.73M)
- Пик продаж: май 2024 ($500K)
